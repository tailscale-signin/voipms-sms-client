<p>Send and receive SMS using your VoIP.ms phone numbers. Search conversations, sync contacts, use notification replies, and open the VoIP.ms Message Center for media.</p>
<p>Open conversations check for messages every 30 seconds. A primary build with a configured Firebase relay can wake when a number receives a message. Both the primary and F-Droid builds support scheduled background recovery. Check delivery status for each number in Synchronization settings.</p>
<p>The default dark theme uses cyan accents from GPT Mobile. Light and system themes are also available.</p>
<p>Requires a VoIP.ms account with API access and an SMS-enabled number. Read the <a href="https://github.com/tailscale-signin/voipms-sms-client/blob/master/HELP.md">setup guide</a>.</p>
